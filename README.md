# ResNovae · L'utilizzo dell'AI nella sfera personale

Progetto del corso di **Human-Computer Interaction (HCI)**, a.a. 2026-2027.

Il progetto esplora come l'intelligenza artificiale, nata come strumento di supporto per lo studio e il lavoro, stia entrando anche nelle sfere più intime e personali: come cambia il nostro modo di comunicare e quali confini emotivi, opportunità e criticità emergono quando affidiamo all'AI uno spazio nelle relazioni interpersonali.
